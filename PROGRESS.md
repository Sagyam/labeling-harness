### Judgment calls the owner should know about

1. **Skip writes no label** (DECISIONS D14). The spec says every write creates a `segment_labels`
   row; a skip is the exception, because a deferral is not a decision about the transcript and a
   label row for one would corrupt every disposition statistic.
2. **Audio is streamed, never redirected to a presigned URL** (D15). One code path for both storage
   backends.
3. **`/tasks/next` marks the task `in_progress`** (D16), which is what makes resume work.
4. **Elapsed time is client-reported** (D17), because server processing time is not the quantity of
   interest.
