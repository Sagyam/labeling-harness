# Environment for notebooks/EDA.ipynb. Deliberately separate from backend/pyproject.toml: the
# harness itself must not grow a pandas/matplotlib/torch dependency (D43 keeps the runtime image
# thin and hash-checked), and nothing here is imported by app code. `make env` builds it:
#
#   uv venv --python 3.13 notebooks/.venv
#   VIRTUAL_ENV=notebooks/.venv uv pip install -r notebooks/requirements.txt \
#       --extra-index-url https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match
#   notebooks/.venv/bin/python -m ipykernel install --user \
#       --name labeling-harness-eda --display-name "labeling-harness (EDA)"
#
# CPU-only torch: the voice-print section runs on a 16-thread CPU. The speaker encoder is
# speechbrain/spkrec-ecapa-voxceleb, chosen because it is UNGATED -- the pyannote diarization
# pipelines are gated=auto on the Hub and need an accepted-conditions token this project does not
# carry.
